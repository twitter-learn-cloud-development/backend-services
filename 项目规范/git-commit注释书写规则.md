### 常用 type（你这个项目很适合这些）

* **feat** → 新功能（比如新增 Canal 消费链路）
* **refactor** → 重构（你这次就是）
* **fix** → 修 bug
* **perf** → 性能优化
* **chore** → 构建/依赖/杂项
* **docs** → 文档

# 🎯 给你一个核心建议（很重要）

你现在这个系统已经不是“CRUD 项目”了，而是：

> **事件驱动 + Outbox + Binlog + MQ 解耦系统**

所以 commit 不要再写“做了什么操作”，而要写：

👉 **“系统怎么流动变了”**

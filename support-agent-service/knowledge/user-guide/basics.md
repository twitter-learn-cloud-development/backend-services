# Twitter Clone 基础导航与操作入口

适用：当前 Web 用户界面；更新于 2026-10-02。本文介绍产品操作，不是平台社区处罚政策。

登录自己的账号后，可以通过导航栏打开首页 `/`、探索 `/explore`、通知 `/notifications`、私信 `/messages`、书签 `/bookmarks`、个人资料 `/profile`。导航栏的“发推”按钮会回到首页，它本身不直接提交推文。请在页面内完成内容填写并确认实际发布结果。

“AI 助手”入口是 `/agent`；“工作流定制”入口是 `/agent/workflow`。如果只是想提问，先进入 AI 助手，不需要先搭建工作流。

通知入口可以显示未读数量；查看通知与执行通知相关操作以页面实际结果为准。右下角客服的回答不是通知已读、消息发送或推文发布的执行凭据。

账号相关修改、发布、点赞等操作需要相应登录权限。网页可以展示的资源，不表示客服能查询全部数据。退出登录可使用导航栏退出按钮，确认后退出；共享设备使用完请退出账号。

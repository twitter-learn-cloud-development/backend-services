# Workflow 运行记录与常见问题

适用：`/agent/workflow`；更新于 2026-10-02。

## 保存后从哪里打开？

在工作流选择框中选择已保存流程。每次成功更新会形成新版本；版本选择用于查看对应定义。工作流列表和修改受当前登录用户的所有权限制，换账号后不应期待看到原账号的私人流程。

## 运行测试为什么没有出现在 AI 助手聊天历史？

编辑器测试运行默认不持久化为 AI 助手对话。点击“运行记录”，选择一条记录查看状态、输出与节点信息，不要因为对话栏没有消息而重复执行可能有副作用的流程。

## 如何判断成功、失败或等待处理？

以运行记录状态为准。“success”表示运行成功；“failed”是失败；“suspended”是挂起，可能需要审批或人工输入；“canceled”是已取消。“compensated”表示主流程失败或取消后的补偿完成，不等于原任务成功。

界面有“停止运行”并要求确认。停止不等于撤销已发生的外部操作。“运行回放”只查看已有事件与结果，不重新执行工作流。不要为了看结果再次点击 Run。

## 模型连接失败怎么办？

选择报错的 LLM 节点，检查模型配置是否对应当前可用服务。界面会对本地模型未连接给出提示；只有部署提供可用模型时才切换。不要向客服发送密钥。

## 联网搜索或发布给 Agent 不可用怎么办？

这些功能可能未在当前环境启用或缺少可用配置。先使用当前可用的对话或站内检索能力，或联系维护者核实可用范围。不要重复发布、绕过审批或假定已上线。

## 保存和“发布给 Agent”有什么关系？

先成功保存并选定版本，才可尝试“发布给 Agent”，填写适合调用它的说明。发布记录固定到一个版本；修改草稿不自动替换已发布版本。只有服务确认成功后，才视为已发布。是否允许发布以及哪些工具能执行，由服务端当前权限和能力约束决定。

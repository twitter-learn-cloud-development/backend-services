# Workflow 创建、保存和运行步骤

适用：工作流定制页面 `/agent/workflow`；更新于 2026-10-02。

1. 使用自己的账号，从导航栏进入“工作流定制”。在工作流选择框中选择已有流程，或保持未选择工作流的默认画布。先从默认对话流程开始，避免首次就加入会产生写操作的工具。
2. 填写工作流名称。通过组件面板添加节点到画布，连接节点的输出端和输入端。点击节点设置属性；不要在描述、提示词或属性文本中粘贴密码、登录令牌或服务密钥。
3. 检查连线。选中连线后可按 Delete/Backspace 删除，也可双击连线删除；删除节点会同时移除相关连线。输入字段编辑时留意当前选中对象。
4. 如需限制执行量，打开“运行预算”，设置节点执行次数、并行节点数、运行超时、Token 等限制。预算是执行上限，不是必然消耗或成功保证。
5. 点击“保存发布 (Save)”。该按钮通过服务端保存当前账号的工作流定义与版本，不是只存于浏览器本地；它不等同于“发布给 Agent”，也不发布推文。看到保存成功后，可重新选择该工作流核对节点、连线和配置。失败时不能认为内容已经持久化。
6. 点击“运行测试 (Run)”。当前实现会先保存画布，再询问本次启动内容；输入非空内容后调用真实运行接口。运行不是静态预览，可能消耗模型额度或执行工具。
7. 等待运行结果，并打开“运行记录”查看实际状态与节点情况。编辑器的测试运行默认不写入 AI 助手对话历史，不能据此认定运行丢失。

重要：即使选择了历史版本，当前“运行测试”也会先保存当前画布并更新选定版本，再运行；不要将它理解成完全不保存的历史版本回放。“运行回放”是独立的只读入口。

若画布包含 PublishTweet，页面会明确提示会真实发布推文并要求确认。只有你明确需要该写操作时才继续；默认对话流程不包含自动发推。

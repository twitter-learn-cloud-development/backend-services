# 用户端助手前端蓝图与 Demo

日期：2026-10-02。当前实现目录：`frontend/`，独立本机入口 `127.0.0.1:5174`。

## 产品与视觉

以自然语言咨询为唯一主入口。桌面三栏为当前浏览器会话、聊天、上下文说明；移动端把会话收进抽屉，右侧说明进入帮助面板。浅米白、海军蓝和珊瑚橙组成「小栖」视觉，保持大留白、克制边框和舒适正文行距。

欢迎页示例只填入问题，由用户发送；它们不指定真实工具或问题类别。真实能力选择仍由 Supervisor/Worker 完成。真实答复忠实显示 `answer`，不从文字推断推文卡片、日期或可见性。推文跳转使用后端可信 `citations`；`evidence_refs` 展示为安全引用，没有证据详情接口。

## 代码与链路

Vue 3 + TypeScript + Vite 与现有 Twitter Web 对齐。独立工作台在 Python 项目内；紧凑 WidgetView 使用相同会话/API client，原站在 App.vue 注册全站悬浮 Host，不跟随 RouterView 销毁。助手使用内存状态，不额外引入状态库。

`App.vue` 负责布局与交互；`useWorkspace.ts` 负责模式、当前账号与内存会话；`api.ts` 负责接口校验与请求；`demo.ts` 负责明确标识的示例回复。演示不调用模型，任意问题仅展示交互说明；固定场景只由显式示例选择触发，不能宣称真实查询。

Vite 仅监听 loopback。代理明确白名单：Chat/readiness 指向 8000，登录/当前用户指向 9638。没有通用 `/internal/` 代理。部署态代理与 CORS/会话认证策略在集成现有 Web 时另行落实；Vite preview 仅用于静态演示，不提供真实 API 代理。

当前 Gateway 的默认开发 Origin 为 `http://localhost:5173`。Demo 的登录/资料代理仅把精确的本机 5174 Origin 映射到该开发 Origin，其余 Origin 保留原验证。该配置用于本机开发；集成正式 Web 后由部署层设置精确允许列表。

## 状态与认证

- 演示和真实会话分开；登录/退出清理真实会话。JWT 只保存在内存，密码在登录完成后清空，不展示、不写 URL/Storage。
- 首轮省略 `conversation_id`；验证成功响应后保存真实 ID，续聊原样传回。
- 新逻辑请求使用新 UUID Idempotency-Key；明确重试复用原 key 和完整正文。发送中不并发提交同一会话。
- 401 重新登录；403 提供新建对话；409 保留问题并说明冲突；429/503/504/网络错误保留问题，不自动无界重试。
- 停止仅表示前端停止等待；服务端执行状态可能未知。
- 当前 API 没有历史列表，因此侧栏明确标注「本次浏览器会话」，刷新后清空。服务端 Mongo 历史仍保留，不能将前端内存列表描述为已同步。
- 处理中只显示等待答复，不伪造模型思考、内部任务或工具阶段。

## 验证与后续

验证界面演示、模式隔离、输入法与键盘发送、请求重试契约、失败反馈、移动端以及正常登录后的真实 Chat。全站挂载、账号复用和推文引用已实现；后续为权威历史列表/证据详情 API、安全 Markdown 排版和 SSE 生命周期展示。

F1 历史结果：初版构建、11 项契约测试与浏览器夹具通过，当时未调用真实模型。F2 已扩大为 29 项 API/引用/身份竞态测试、窗口4状态/7错误/消息桥安全夹具与真实全站验收：2 用户、1 推文、2 次模型问答，登录共享身份、可信引用和幂等回放、真实详情路由、收缩保留、Workflow 知识续聊、手机布局、跨用户 403 与匿名 401 通过。报告与截图位于 `frontend/artifacts/`；测试数据保留。完整范围见 `frontend-acceptance-v2.md`。

Host 懒加载 iframe，收缩保留 DOM；postMessage 校验精确 Origin/source，JWT 不进入 URL 或助手 Storage。资料未完整时撤销旧身份；换账号、退出和迟到回复使用 session revision 隔离。原站已有 LocalStorage 认证未重构，但 Login 的敏感调试输出已移除。

引用由 BUSINESS_API 校验记录生成，ID 保持字符串；知识文档、演示或模型文字不能生成链接。前后端拒绝外站、非法路径、无本轮证据和重复引用，详情页再次鉴权。6 篇源码核对的操作指南通过现有 published knowledge Capability 检索，没有新增问题类别或工具分流；未编造处罚规则、时限和申诉承诺。

本机仍需 5174 助手进程与 5173 原站及后端。跨主机、生产域名/TLS/反代不属于本轮交付。移除原站 App.vue 的 Host 挂载并重建前端即可撤回入口；响应增量字段向后兼容，没有数据库结构迁移。指南可按专属文档 ID 版本化撤回，不删除共享集合。
